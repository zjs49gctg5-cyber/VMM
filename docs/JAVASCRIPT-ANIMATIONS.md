# JavaScriptCoreカスタムアニメーション

macOS標準のJavaScriptCoreで、ユーザーが書いたJavaScriptからアニメーションキーを生成します。コードは専用ヘルパープロセスで実行し、結果を既存のAnimationTrackへ変換します。プロジェクトの読み込み・プレビュー再生・動画書き出しではJavaScriptを実行しません。

## 操作

1. アイテムを選択 → アニメーション編集 → カスタム →「JavaScriptで作成・編集…」。
2. サンプルから上下の波・円周運動・減衰振動を選ぶか、コードを編集します。「出力する項目」で対象と基準値への加算／絶対値を指定します。
3. 必要に応じてパラメータ定義のJSONを編集し、表示された数値を調整します。割合は％表示、上下キー・ステッパーは既存の数値入力と同じです。
4. 「テスト生成」は検証して生成キー数を表示し、プロジェクトを変更しません。「キーフレームを生成・適用」は宣言した項目のキーだけを置換します。通常のキー編集・Undo／Redoを使えます。
5. 「現在の設定を拡張JSONに書き出す…」でコード・調整した数値・乱数シードを共有できます。数値は定義の初期値として保存します。同じ下書きからの再出力は同じ拡張IDを使うため、再導入時に更新できます。設定 → 拡張から導入すると、カスタム画面の定義候補に表示されます。「JavaScriptサンプルを追加」でも導入できます。

生成中はキャンセルできます。エラー時は画面に診断を表示して既存のプロジェクトを維持します。生成中にプロジェクトが変更された場合、古い結果は適用せず再生成を求めます。

## 編集内容の保護と編集補助

- コード・未完成のJSON・数値・出力項目・乱数シードを、変更後約0.3秒と閉じる／サンプル切り替え時に下書き保存します。サンプルごとの下書きを保持し、元のサンプルへ戻ると編集内容を復元します。「下書きを破棄…」だけが確認後に初期状態へ戻します。
- 下書きはVMMの設定フォルダ内 `AnimationDrafts` に置き、プロジェクトの保存先・アイテムごとに区別します。未保存プロジェクトではセッションを区別し、編集画面を開いたまま保存／別名保存すると保存先へ引き継ぎます。未保存のままアプリを終了した場合、次回の新規セッションへは自動で関連付けません。`.vmm` を他のMacへ渡すとき、未適用の下書きは含まれません。適用済み定義は従来どおりプロジェクト内に保存します。
- 読み込めない下書きはUUID付きのコピーで保護します。保存に失敗すると画面に表示し、「閉じる」ボタンは成功するまで編集内容を保持します。
- カスタム欄で変更した未適用の数値を編集画面へ引き継ぎます。既存の下書きがある場合も、カスタム欄で明示的に変更した値は反映し、コードは保持します。無関係な拡張の導入・無効化では入力中の値をリセットしません。
- コード欄に行番号・色分けを追加し、JavaScriptCoreが報告するエラー行を強調してスクロールします。アプリ側の実行制限・出力形式エラーなど、コード内の行を特定できないものは行番号を表示しません。
- パラメータの追加・削除・ID・表示名・単位・最小／最大／初期値はフォームで編集できます。JSONの直接編集も選べます。IDを変更する場合、コード内の `input.params` 参照も合わせて変更してください。
- 出力するプロパティ名と生成対象フレーム数、時間／キーの上限を表示します。20,000フレームを超えるアイテムは生成前に停止し、分割を案内します。音声アイテムでは音量フェードのサンプルを使います。

コード・出力項目・パラメータ定義・適用した値・乱数シードと、生成済みキーを `.vmm` 内に保存します。再度「JavaScriptで作成・編集…」を開くと保存済みの定義を編集できます。拡張が未導入でも保存済みキーで再生・書き出しでき、再生成は明示的に行います。複数定義の履歴は保存せず、最後に適用した定義1件を保持します。JSONの宣言型定義も引き続き使えます。

## 関数の契約

同期関数 `animate(input)` を定義し、出力項目名と有限の数値を持つオブジェクトを返します。返す項目は宣言した出力と完全に一致させてください。Promise・async関数は対応しません。

```javascript
function animate(input) {
  const phase = input.t * Math.PI * 2 * input.params.cycles;
  return { y: Math.sin(phase) * input.params.amplitude };
}
```

| 入力 | 内容 |
| --- | --- |
| t | アイテム内の進行0〜1 |
| seconds / duration | 開始からの秒数／アイテムの長さ |
| fps / frame | 生成するプロジェクトFPS／フレーム番号 |
| width / height | プロジェクトの幅／高さ |
| params | パラメータID→値の辞書 |
| base | 対応するプロパティ名→基準値の辞書 |
| seed | 0〜4294967295の乱数シード |
| random() | シードとフレーム番号から作る0以上1未満の乱数 |

`input`、`params`、`base` は変更できないオブジェクトです。x/yは画面の幅／高さに対する割合、scale・opacity・volumeは倍率／割合、rotationは度です。「基準値に加算」を有効にした項目では返り値を基準値に加算します。絶対値にした項目では返り値を直接設定します。最終値は既存プロパティの範囲に制限します。

`Math.random()` もフレームごとのシード付き乱数です。`Date` は使用できません。関数は時間と入力から値を計算する形で書いてください。1ジョブ内では同じJavaScript環境でフレーム順に呼び出すため、グローバルな可変状態を利用すると生成FPS・区間の長さで結果が変わる場合があります。保存済みのキーは再生順によらず同じ結果になります。

パラメータ定義は既存JSON定義と同じ配列です。`id`, `title`, `minimum`, `maximum`, `defaultValue` が必須で、`unit` は任意です。`unit:"%"` は内部値1が100％です。詳細は [JSON拡張](DATA-EXTENSIONS.md) を参照してください。

## 拡張JSONの形式

JavaScriptを含むパッケージは `version: 2` を使います。実際に読み込めるサンプルは [javascript-motion.vmmext.json](../examples/extensions/javascript-motion.vmmext.json) です。version 1の宣言型パッケージと旧 `.vmm` は引き続き読み込みます。旧VMMへJavaScript付きパッケージを渡すと未対応版として拒否されます。

```json
{
  "version": 2,
  "id": "example.js.wave",
  "name": "JavaScriptの波",
  "author": "Example",
  "revision": "1.0",
  "animations": [{
    "id": "wave",
    "name": "上下の波",
    "parameters": [],
    "tracks": [],
    "script": "function animate(i) { return { y: Math.sin(i.t * Math.PI * 2) * 0.1 }; }",
    "scriptOutputs": [{"property": "y", "offset": true}]
  }],
  "presets": []
}
```

`script` と `scriptOutputs` はOptional項目です。任意の `scriptSeed`（UInt32）を指定でき、UI／MCPでシードを省略したときの初期値に使います。省略した旧定義は1を使い、プロジェクト内に適用済みシードがあればその値を優先します。JavaScript定義では `tracks` を空にし、出力項目を `scriptOutputs` に列挙します。宣言型定義では従来どおり `tracks` を使い、JavaScript項目を省略します。導入確認画面はJavaScriptを含むことを表示します。導入・開く・無効化・削除ではコードを実行せず、生成ボタンかMCPからの適用でのみ実行します。

## 実行と負荷の制限

- ソースは64KiBまで。定義ごとのパラメータ・出力項目は12件まで。
- 生成はプロジェクトのフレーム時刻と終端で最大20,000フレーム、各項目500キーまで。キー間引きの精度は既存JSON定義と同じです。
- ワーカーの実行は5秒でタイムアウト。CPUの追加上限は6〜7秒、出力は8MiBまで。親プロセスは約20msごとにメモリを確認し、512MiB超で終了します。メモリ値は監視による上限で、瞬間的な使用量の厳密な保証ではありません。
- キャンセル・期限超過・メモリ超過時はヘルパーを終了します。アプリの編集画面はJavaScriptを評価しません。
- JavaScriptCoreにアプリのSwift/Objective-Cオブジェクト、ファイル、ネットワーク、プロセス操作、Webブラウザ／Node.jsのAPIを公開しません。外部モジュール・npm・fetch・requireは使えません。
- ヘルパーはJITを無効にして実行します。OSサンドボックスでネットワーク・子プロセス・ユーザーファイルへのアクセスを禁止し、標準ライブラリの読み込みと当該ジョブの結果ファイルだけを許可します。隔離の設定に失敗した場合はコードを実行せずエラーにします。
- SDKのsandbox_initは非推奨APIのため、将来のmacOSとの互換性は継続確認が必要です。

高周波はプロジェクトFPSで捉えられる範囲にしてください。異なる出力FPSでは保存済みキーを補間し、式を再評価しません。任意のピクセルフィルタやトランジションを実行する機能ではなく、既存プロパティのアニメーション生成です。

## MCP・ビルド・配布

MCPの `vmm_animation_applyDefinition` はJavaScript定義にも対応します。`packageID`, `definitionID`, `clipID`, 任意の `values`, `seed` を指定するとジョブIDを返します。`vmm_job` に `jobID` を渡して結果を確認し、`vmm_animation_cancelGeneration` で生成を中止できます。`vmm_state` の `generatingScript` でも状態を確認できます。MCPは通常起動時に無効で、同一ユーザーの認証付きローカル接続を使用します。

標準の `swift build` はVMMAnimationWorkerも生成します。`scripts/build-app.sh` は `Contents/Helpers/VMMAnimationWorker` を同梱し、ヘルパー→本体の順でアドホック署名します。Developer IDは開発・この機能の利用に必須ではありません。Developer ID署名と公証の手順は[署名・公証](SIGNING-NOTARIZATION.md)を参照してください。JIT・Library Validationの解除用entitlementsは追加していません。
