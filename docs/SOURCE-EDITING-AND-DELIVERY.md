# 素材編集・音声出力・他ソフトへの受け渡し

## 素材のIn/Outと編集

素材ライブラリで動画・音声を再生すると、再生欄に素材In/Outが表示されます。再生位置をIn/Outに指定するか、秒数を入力します。「全範囲」で元に戻ります。この範囲は素材の試聴セッション内だけの指定です。プロジェクトのタイムラインIn/Outとは別です。

- **追加**：範囲を再生位置・選択レイヤーへ配置します。既存アイテムを移動しません。
- **挿入**：全レイヤーの後続を範囲の長さだけ移動します。挿入位置をまたぐ独立したアイテムは分割します。後のマーカーとタイムライン範囲も移動します。
- **上書き**：選択レイヤーの該当区間だけ置き換えます。前後に残る部分は、素材オフセットとアニメーション時刻を維持します。

各操作は1回のUndoで戻せます。ロックされたレイヤーを移動する操作や、リンク・親子・シーン所属のあるアイテムをまたいで分割／削除する操作は全体を拒否します。先に安全な位置で分割するか、関係を解除してください。

タイムラインの動画・音声を右クリックすると次の操作を使えます。

- **素材をスリップ編集**：タイムライン上の位置・長さは維持し、素材内の使用位置だけ変更します。移動量は秒指定で、正なら後の部分を使用します。リンクした音声・映像も追従します。
- **右隣との境界をロール編集**：右側の隣接アイテムとの境界だけ動かし、2つを合わせた開始・終了は維持します。両素材に余りが必要です。現在は独立した音声・映像アイテムが対象です。

素材端を超える操作は無変更でエラーを表示します。音声のIn/Out・移動量は小数6桁まで表示し、フレーム未満の調整ができます。音声出力のタイムスケールは48,000です。数値欄の上下キー／ステッパーは1秒ずつ、精密な値は直接入力します。

## クロスフェード・WAV

先頭と末尾をずらして重ねた2つの音声付きアイテムを選び、タイムラインを右クリック → **選択した2音声をクロスフェード**。重なり全体に等パワーのフェードアウト／インを設定します。位置や長さは変えません。重なりは最大60秒です。自動で素材を延長・移動しないので、先に重なりを作ってください。

アニメーション編集の「音声フェード」で直線／等パワーを選べます。従来プロジェクトのフェードは直線のままです。音量・フェード・EQ・速度・音程・ダッキング・親の音量・マスター設定は、プレビューと出力で同じ計算を使います。等パワーは相関のない素材向けで、同一の音を重ねる場合は音量ピークを確認してください。

書き出し設定 → **音声のみ（WAV）**：48 kHz・24 bit・ステレオで出力します。書き出し開始／終了範囲を使い、先頭・途中・末尾の無音を保持します。映像を描画せず、動画出力と共通の音声合成処理を使用します。WAVの範囲はサンプル単位に丸めます。

## ProRes・XML

書き出しコーデック **ProRes 422** を選ぶと、形式はMOVになります。ビットレート／品質の数値指定は使用しません。音声は48 kHz・24 bit PCMです。編集用中間素材に向いており、配信用H.264／HEVCより容量が増えます。

**他編集ソフトへ（描画済みXML・ProRes・WAV）** は新規フォルダに以下を作ります。

| ファイル | 内容 |
|---|---|
| master.mov | VMMの描画と音声処理を焼き込んだProRes 422 + PCM |
| audio.wav | 同じ音声だけを48 kHz・24 bitステレオで出力 |
| timeline.fcpxml | Final Cut Pro向けFCPXML 1.10 |
| timeline-premiere.xml | Premiere等向けFinal Cut Pro 7 XML v5 |
| vmm-edit-reference.json | 元のVMM編集モデル（参照用、素材は含まない） |
| README.txt | 受け渡し内容と制限 |

XMLはVMMのアイテム境界とマーカー位置でマスターを分割します。移行先でカットを組み直せますが、**レイヤー・字幕・立ち絵・エフェクト・キーフレームは焼き込み**です。各設定を移行先のネイティブ編集パラメータへ変換する機能や、XMLのVMMへの再読み込みは含みません。元の編集を残すには通常の`.vmm`を別途保存してください。XMLの時刻は出力FPSのフレーム境界へ丸めます。

既存フォルダは置き換えません。失敗／中止では未完成パッケージを残しません。フォルダを移動した場合は、移行先でmaster.movを再リンクしてください。master.mov内の音声とaudio.wavを同時に鳴らすと二重になるので、差し替える際は片方をミュートします。

FCPXMLは[Apple公式DTD](https://developer.apple.com/documentation/professional-video-applications/document-type-definition)で検証。旧XMLは[AppleのFCP7仕様](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/FinalCutPro_XML/Basics/Basics.html)に沿って生成・構造検証しています。Final Cut Pro／Premiereの実アプリへの読み込みは未検証です。
