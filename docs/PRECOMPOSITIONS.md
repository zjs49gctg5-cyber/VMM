# プリコンポジション

複数の素材を独立したタイムラインにまとめ、メイン側では一つのアイテムとして配置する機能。

## 作成・編集

1. タイムラインで素材を複数選択し、右クリック →「プリコンポジションにまとめる…」。親子・リンク付き素材は関係するアイテムも一緒にまとめる。
2. 名前を付けて作成。選択範囲を0秒開始の内部タイムラインへ移し、メインには新しいレイヤーに一つのアイテムを配置する。元レイヤーの効果は内部で保持し、新しいレイヤーは効果なしにする。
3. アイテムをダブルクリック、または設定欄・右クリックの「プリコンポジションを編集…」で独立ウィンドウを開く。
4. 内部の字幕・画像・動画・音声・アニメーションなどを通常のタイムラインで編集する。素材の追加にも対応する。
5. 「変更を適用」（⌘S）でメインへ反映する。適用前の編集は下書きとして分離され、親のUndoで適用全体を戻せる。閉じる際は未適用の変更を確認する。

内部の編集には独立したUndo/Redoがある。親側の移動・回転・拡縮・マスク・エフェクトは、内部を合成した映像全体へ適用する。音量・フェードは内部音声にも作用する。

コンポの長さは上部で指定する。解像度・fps・プレビューの背景色は素材ライブラリの設定で変更できる。内部のマーカーや再生区間も保持する。背景色は内部プレビュー用で、親へ配置すると背景は透明になる。親とは異なる解像度のコンポは元のピクセル寸法で中央に配置され、拡大率で調整できる。音MAD設定とマスター音声処理は親プロジェクトで管理する。

## 再利用・入れ子

制作ワークスペースの共有ライブラリにあるプリコンポジション一覧から、同じコンポを再配置できる。「複製」も同じ内部定義を参照するので、内部の変更は全配置へ反映される。

一つの配置だけ別内容にする場合は「独立したコピーにする」。コピーしたコンポの内部は別定義になり、その入れ子の参照先は引き続き共有する。配置を全て削除した定義は一覧の右クリックから削除できる。使用中の定義は削除できない。

内部にもプリコンポジションを作成・配置できる。循環参照を拒否し、親子・従来シーンを含む描画の入れ子は15段までに制限する。

配置ごとに移動・左右トリム・分割が可能。トリムと分割は素材の開始位置を保持し、内部の映像と音声を同じ時刻で切り出す。速度変更とタイムリマップはこの段階には含めない。全長を使うメイン側の配置は、内部の長さ変更に合わせて伸縮する。トリム済みの配置はその範囲を保持する。

## 保存と保護

プリコンポジションの定義と配置情報はプロジェクトに保存され、シーンの保存・配置時にも定義と素材を含みます。

内部編集の素材は独立した作業フォルダへコピーする。適用時は新規素材を親へ追加し、既存ファイルを上書きしない。Undo用に作業素材を保持する。開いた後に同じ定義が他画面で変更された場合や親プロジェクトが切り替わった場合は、上書きせず適用を拒否する。

## MCP

認証付きローカルMCPで以下を提供する。通常起動時は無効のまま。

- `vmm_precomposition_create`: 選択素材をまとめる。`name` を指定。
- `vmm_precomposition_update`: `compositionID` と `properties` で内部定義を更新。名前・幅・高さ・fps・長さ・レイヤー・アイテム・マーカー・再生区間・プレビュー背景を編集可能。ネストした配列は全体を置換する。
- `vmm_precomposition_place`: `compositionID` を配置。必要に応じ `start` と `track` を指定。
- `vmm_precomposition_makeUnique`: `clipID` の定義を独立したコピーにする。
- `vmm_precomposition_delete`: 未使用の `compositionID` を削除。

先に `vmm_state` で定義・アイテム・素材のIDを読む。音声再生と書き出しは同じ内部時間の展開を使用し、展開結果は編集変更時だけ更新する。
