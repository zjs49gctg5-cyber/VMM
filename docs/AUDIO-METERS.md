# 音量メーター

## ミックス全体の波形

マスター音量の設定から「ミックス全体の波形」を開き、「波形を解析」を押すと、プロジェクト全体の出力ミックスを波形で確認できます。波形をクリックするとその時刻へ移動します。マスター処理を含む実ミックスを使用し、音声が互いに打ち消し合う場合も反映します。編集後は「再解析」してください。解析は1時間以内で、一時音声ファイルに応じたディスク容量と時間が必要です。

タイムライン左側にL/Rの縦型メーターを常時表示する。タイムラインをスクロールしても固定され、独立ウィンドウのタイムラインにも表示される。下部に最大ピーク、詳細ボタン、保持・警告のリセットボタンがある。詳細はレイヤー別・RMSの数値を表示する。素材ライブラリの「プロジェクト設定」からも詳細を開ける。

- マスターと音声レイヤーごとに、L/Rのピーク、RMS、最大ピーク保持を表示する。目盛りは−60〜0 dBFS。−6 dBFS以上は橙色、0 dBFS以上は赤色。
- 白い線は最大ピーク保持、細い白い帯はRMS。ピークの表示は18 dB/秒で下がり、画面更新の間に発生した短いピークも集計する。RMSは更新間隔のサンプル平均で、バッファの間は直近の値を最大300ms保持する。
- 0 dBFS以上の警告と最大値は一時停止後も残る。「保持・警告をリセット」で解除する。プロジェクトを切り替えると履歴を消す。
- マスター出力の減衰、音量キーフレーム、正規化ゲイン、EQなどを通った各音声の測定値を使用する。主ミキサーのタップは出力音量より前なので、1倍未満の出力減衰を測定値へ反映する。1倍以上の増幅はEQですでに反映されている。
- **マスターは共有音声エンジンの実ミックス**を、コンプレッサー／リミッター通過後に測定する。逆相や時間差を含む実際の波形のPeak/RMSになる。レイヤー別は各アイテムの振幅合計上限の推定を維持する。
- リアルタイム表示はSample Peak/RMS。プロジェクト設定の「ミックス解析・音声処理…」と書き出し前チェックで、出力範囲のIntegrated LUFS、Sample Peak、4倍補間True Peak推定、超過サンプル数を解析できる。ハードウェア音量・エンコード後True Peakは含まない。
- プロジェクト設定からマスターコンプレッサー／サンプルピークリミッターを有効化できる。既存の選択音声LUFS正規化はアイテム設定から使用する。

保存モデルにはOptionalの`masterDynamics`とクリップの`pan`を追加。旧プロジェクトでは音声処理無効・パン中央になる。メーターの保持・警告は編集セッション中だけの情報。

[音声ミックスの設定](AUDIO-MIX-IMPROVEMENTS.md)も参照してください。
