# 設定の分類

## どこを開くか

| ウィンドウ | 項目 |
| --- | --- |
| 設定 | 一般（言語）、音声エンジン、ショートカット、拡張、保存とライブラリ、復元履歴 |
| ワークスペース設定 | 外観（テーマ・文字・アイコン・ツールバー）、レイアウト（表示・ウィンドウ分離）、タイムライン表示（サムネイル・波形）、プレビューとキャッシュ |
| 書き出し設定 | 出力テンプレート・サイズ・FPS・形式・品質・範囲・事前チェック・出力キュー |
| 制作機能 | 素材管理、台本、キャラ、発音辞書、共有ライブラリ |

設定はアプリの動作と保存、ワークスペース設定は編集画面の見た目と表示を扱います。制作機能には編集作業の項目があります。解像度・プロジェクトFPSなどの作品固有の設定は、引き続きメイン画面のプロジェクト設定にあります。

ワークスペース設定の「外観」では、テーマを「macOSに合わせる」「ライト」「ダーク」から選べます。初期設定はmacOSに合わせるです。テーマは編集画面と独立ウィンドウに適用され、動画の見た目や書き出しには影響しません。

## 導線

- メイン画面の「設定」ボタンから、アプリ設定・ワークスペース設定・書き出し設定を開ける。
- ツールバーが画面幅に収まらない場合は横スクロールして項目を表示できる。表示形式とアイコン倍率はワークスペース設定の「外観」で変更できる。
- 設定画面上部と制作機能上部に「ワークスペース設定…」があります。
- 設定の「一般」から「外観の設定を開く」で該当タブへ直接移動。
- ワークスペース設定から「アプリの設定…」で戻れる。
- 制作機能から設定・書き出し設定も直接開ける。
- アプリメニューの「復元履歴…」からも開けます。

## 復元履歴

復元履歴は、保存・バックアップの管理として設定にあります。「保存とライブラリ」で自動保存の間隔、保持数、保存先、共有ライブラリの場所を設定し、「復元履歴」で実際のファイルを選びます。両タブには相互に移動するボタンがあります。

復元した内容は別名で保存できます。各設定ウィンドウは既存のウィンドウを再利用し、タブの選択を保持します。

## ショートカット

設定の「ショートカット」で操作プリセットを選べます。各操作の欄に `cmd+shift+s` や `space` などを入力し、「適用」またはReturnで確定します。同じキーが使われている場合は競合先が表示され、適用できません。「標準に戻す」は選択中のプリセットの割り当てに戻します。
