# 素材の読み込み形式

VMMの素材読み込みは、画像にAppKitのNSImage、動画・音声にAVFoundationを使用します。拡張子だけで対応を決めず、読み込み時に画像、動画フレーム、音声サンプルをデコードできるか確認します。同じ拡張子でもコーデックによって読み込めないことがあります。

| 種類 | 主な形式 | 備考 |
|---|---|---|
| 画像 | PNG、JPEG/JPG、TIFF、BMP、GIF | 透明画像に対応。GIFアニメーションは埋め込まれた再生時間・ループ回数に従って再生します。10,000フレームを超えるGIFは先頭を静止画として扱います |
| OSが対応する追加画像 | HEIC/HEIF、WebP、SVGなど | NSImageの対応状況はmacOSのバージョンによって変わります。読み込んだ画像は描画時にラスタライズします |
| レイヤー付き立ち絵 | PSD | VMMのPSDデコーダーでレイヤーを読み込み。表情・口パク・目パチを設定できます |
| 立ち絵配布アーカイブ | PSD入りZIP | ZIP内のPSDを素材登録します。一般の画像／動画をまとめたZIPを展開する機能ではありません |
| 動画 | MP4、MOV、M4Vなど | H.264・HEVC等、macOSがデコードできるもの。AVI・MPEGなども環境とコーデックによります |
| 音声・BGM | WAV、MP3、M4A、AIFF、CAFなど | PCM・AAC等、AVFoundationがデコードできるもの |

MKV・WebM・Ogg等のための追加デコーダーは同梱していません。保護されたメディアも対応保証しません。読めない素材は対応コーデックのMP4、PNG、WAV等に変換してから読み込んでください。

素材読み込みボタンにマウスを置くと、主な対応形式を表示します。取り込んだ元ファイルはコピーし、原本を変更しません。PSDは必要なレイヤー画像もプロジェクトに含めます。

## プロジェクトや共有素材を開けないとき

`.vmm` は素材を含むパッケージです。外部のプロジェクトや共有素材を開くとき、内部の情報ファイル、`Media` フォルダ、素材ファイルがシンボリックリンクになっている場合は、安全のため読み込みを拒否します。プロジェクトを開く際に通常の素材ファイルが見つからない場合は、欠落素材として扱います。

以前のVMMで作成したプロジェクトなど、内部にリンクが保存されたプロジェクトを開けない場合は、次の手順を試してください。

1. Finderでプロジェクトを複製し、原本を保管します。
2. 複製を右クリックして「パッケージの内容を表示」を選びます。内部のリンクを、リンク先にある実際のファイルやフォルダに置き換えます。素材ファイルは元のファイル名を変えないでください。
3. 複製したプロジェクトを開きます。素材が見つからない場合は、素材ライブラリの「…」→「素材管理…」から再リンクします。

プロジェクト自体へのシンボリックリンクや、Finderから明示的に選択した素材へのリンクは利用できます。素材を選んだ場合は、リンク先の実ファイルを取り込みます。

## 素材以外の読み込み

- `.vmm`：ファイルメニューの「開く」からVMMプロジェクトを開きます。
- `.pfv`：PSDの表情・お気に入り設定から読み込みます。素材ライブラリに追加するファイルではありません。
- `.vmmfx.json`：VMMプリセットの「プリセットを読み込む」から読み込みます。
- `.ymmp`、AviUtlプロジェクト、Windows DLL／YMMプラグイン、Luaスクリプトは直接読み込めません。

UTF-8のTXT脚本、キャラ字幕プリセットのJSONも制作ワークスペースから読み込めます。動画書き出しはMP4/MOVのH.264・HEVC映像とAAC音声、またはMOVのProRes 422映像とPCM音声に対応します。音声のみのWAV出力も利用できます。
