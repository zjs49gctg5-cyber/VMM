# PSDTool / PSDToolKit互換範囲

VMMは、PSD素材・PSDToolの選択規則・PFVのお気に入りを扱います。AviUtl上で動くPSDToolKit本体やLuaスクリプトを実行する機能ではありません。PSDToolKitの操作画面・アニメーションパラメーター・プロジェクトの完全互換は保証しません。

| 項目 | 対応 |
|---|---|
| PSD RGB・8bit | 対応。元PSDと展開したレイヤー画像をプロジェクトに同梱 |
| 圧縮 | Raw / PackBits RLE / ZIP / ZIP Prediction |
| 日本語レイヤー名・入れ子グループ | 対応 |
| 通常合成・レイヤー不透明度 | 対応 |
| 通過グループ | 不透明度100%のものに対応 |
| `!` 必須表示 | 親が表示される間、非表示にできない |
| `*` 排他選択 | 同階層の `*` 項目から1つ選択。通常チェック項目は独立 |
| `:flipx` / `:flipy` / `:flipxy` | 同名の通常レイヤーと対で反転時に差し替え。グループの対応する子も切り替え |
| PFV v1 | 読込・適用・出力。エスケープ、同名レイヤーの番号、親フォルダーのフィルターに対応 |
| PFVシンプルビュー | お気に入りボタンとして表示。PSDToolと同一の専用UIは未実装 |
| 口パク | 割り当てた開き口／閉じ口をVOICEVOX音量で切り替え |
| 目パチ | 指定した閉じ目と通常の目を一定間隔で切り替え |
| ZIP | 通常ZIPの保存／Deflate、日本語CP932・UTF-8名。PSD全件を読み込み、readmeを保持 |
| PSB、CMYK、16/32bit | 未対応。読み込み時にエラーを表示 |
| マスク・クリッピング・特殊合成・レイヤー効果・文字・ベクター | 未対応。対応しない情報を検出したPSDは読み込み時にエラーを表示 |
| 暗号化ZIP・分割ZIP・ZIP64 | 未対応 |
| PSDToolKit `.anm` / `.obj` / Lua、AviUtlプロジェクト | 未対応 |
| あいうえお口形 | PSD内の母音レイヤーを割り当て、VOICEVOXの音声生成時のクエリから時刻を推定。未割当・時刻を取得できない音声では従来の開閉に戻る |
| 5段階目パチ・PSDToolKit固有の速度設定 | 未対応 |

同じレイヤー構成を持つPSDに対してPFVを適用してください。見つからないレイヤーパスがあるPFVは、エラーを出して適用しません。ZIP同梱PFVは、各PSDで解決できるお気に入りだけを取り込みます。フィルター付きお気に入りの書き出しでは意味を保持するため、フォルダー名と階層をVMMが組み直します。元PFVのバイト列・フォルダー構成をそのまま保存する方式ではありません。

口・目は同じグループの `*` レイヤーを指定するのが基本です。一般のチェック式レイヤーを指定した場合は排他化されないため、作者がPSDTool対応の命名を行った素材を推奨します。レイヤー名から一部の口・目を初期候補として設定しますが、アニメーションは利用者がオンにするまで動きません。

母音別口パクは、立ち絵のPSD設定で「音声エンジンで口パク」と「母音に合わせて口を切り替える」を有効にし、あ・い・う・え・おに対応する口レイヤーを割り当てます。VOICEVOXで音声を再生成すると、合成時の子音・母音長から口形の時刻を推定して音声素材に保存します。推定は完全な音声解析ではなく、音声とタイミングがずれることがあります。旧音声、長さが整合しない音声、音素長を提供しないAivisSpeech・Style-BERT-VITS2・Qwen3-TTSは、従来の音量による開閉を使います。口形が未割当の場合も開閉を使います。自動口パクは口の表情キーフレームより優先され、目パチは独立して動きます。トリム・分割・再生速度変更は音声の元の時刻に合わせて反映します。

インポート上限は512MB、PSDキャンバス3200万画素、2000レイヤー、レイヤー展開合計1億2000万画素です。対応外のPSDはPhotoshop等で対象部分を通常レイヤーに統合してから読み込んでください。
