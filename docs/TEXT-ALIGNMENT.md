# 文字の配置

テキスト／セリフのアイテム設定「基本」→文字サイズの下に「文字の配置」を常時表示します。左揃え・中央揃え・右揃え・等間隔を選択でき、変更はUndo／Redo可能です。

配置する枠はアイテムのX位置を中心とし、幅は「フォント・文字組み」→「字幕の最大幅」で指定します。左／右揃えはその枠の端へ寄せます。等間隔は各行の文字間に均等な余白を追加し、最終行も枠の幅に広げます。1文字の行は左端に配置します。文字送りでは、全文の配置を維持して順に表示します。

`TextStyle.alignment`はOptionalで、未指定の既存プロジェクトは従来の中央揃えを維持します。MCPの`vmm_clip_update`／`vmm_selection_update`にも同じ`textStyle.alignment`（`left`、`center`、`right`、`distributed`）を使用できます。描画キャッシュとプレビュー操作の選択枠にも反映します。
