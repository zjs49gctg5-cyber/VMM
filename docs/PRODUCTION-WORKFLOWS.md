# 制作ワークフロー

外部操作はMCPを使用します。以下の操作名には `vmm.` を付けてMCPツールから呼び出せます。[接続手順](CONTROL-MCP.md)を参照してください。

## 書き出し前チェック

書き出し設定の「書き出し前チェック」で、素材の欠落、変更済み／未生成のセリフ、画像マスク、フォント、素材終端、出力範囲を確認できます。対象の警告をクリックするとそのアイテムへ移動します。実際の書き出しとキューへの追加でもチェックします。エラーは出力を止め、警告は内容を確認して出力できます。

出力先指定後は空き容量も確認します。容量は指定ビットレートと時間から算出した概算に余裕を加えた値です。一時ファイルやキューのスナップショット容量までは保証しないため、出力先と作業ディスクに余裕を確保してください。

## 動画・音声のリンク

### 選択したアイテムの無音カット

タイムライン上の音声または動画を右クリックし「無音カット」を開きます。閾値・最短無音・前後の余白を設定し、「無音を解析」を押してください。候補の時刻は選択アイテムの先頭を0秒として表示します。カットしたい区間をチェックして適用します。選択した音声・映像とそのリンク先を同時に分割し、残った部分を詰めます。対象は開始位置と長さを揃え、対象レイヤーのロックを解除してください。親子関係やシーン制御を持つアイテム、音声フェードのあるアイテムやリンク先、素材の範囲を超えたアイテムは対象にできません。速度・EQ・ピッチ処理を使う場合、切断点付近の音が変わる場合があります。後続のアイテムとマーカーは移動しません。適用後は1回のUndoで戻せます。

解析は元素材の音量で行い、イコライザーや音量エフェクトの結果は含みません。解析後に設定やプロジェクトを変更した場合は再解析してください。

動画から音声を分離すると、映像と音声を自動的にリンクします。タイムラインの右クリックで、同じ開始時刻・長さの映像／音声を手動リンク、またはリンク解除できます。時間移動、トリム、速度変更、分割、コピー、複製、削除を連動し、コピー先は独立したリンクになります。音量・映像エフェクトは個別に編集できます。リンク先がロックされている場合は一括変更を拒否します。

## プロジェクトのキャラ

キャラ画面の「プロジェクトのキャラ」で、音声エンジン／話者、字幕の色・フォント・装飾、立ち絵・PSD表情・口パク・位置をまとめて保存します。共有プリセットからの追加も可能です。「選択に適用」「このキャラの全アイテムへ反映」で既存アイテムへ適用します。定義を変えただけで既存の編集を上書きしません。脚本読み込みではプロジェクトのキャラ名を優先します。

## 書き出しキュー

書き出し設定で出力先を指定して「書き出しキューへ追加」すると、その時点のプロジェクト、素材、出力設定をコピーして保存します。後から編集しても待機中の出力内容は変わりません。順番変更、失敗・中止後の再試行、現在の出力の中止、この出力後の停止に対応します。

アプリを再起動するとキューは停止状態で復元します。実行途中だったジョブは待機へ戻り、「キューを開始」で再開します。既存ファイルの置換は追加時に明示した場合だけ許可します。追加後に同名ファイルが作られた場合も保護します。

キューは最大100件。スナップショットは設定用ディレクトリの `ExportQueue/<UUID>/snapshot.vmm` に保存し、成功またはジョブ削除で片付けます。失敗・中止では再試行のため保持します。通常の即時書き出しとキューの出力は同時に実行しません。

## シーンライブラリ

共有ライブラリの「シーンライブラリ」で選択アイテムを保存します。親子とリンクの関連アイテムも含み、素材ごと独立した `.vmm` に保存します。「現在位置に配置」で新しいレイヤーへ複合グループとして挿入します。IDと素材の作業ファイル名を振り直すため、元の編集と衝突しません。

シーン制御の移動・変形・アニメーションが内部へ反映されます。内部アイテムはタイムラインで直接編集でき、内部の調整エフェクト・トランジションはシーン内に適用します。外部のオブジェクトへ内部の調整エフェクトを適用しません。背景は透明として合成し、出力解像度・FPS・マスター音量は配置先のプロジェクト設定に従います。異なる解像度間では文字サイズなどのピクセル指定を必要に応じて調整してください。

シーン制御は子を持つため一括分割はできません。全体のクリップ範囲で表示・音声を制限でき、内部は個別にトリムできます。「シーンを解除」は、全体の変形・アニメーション・効果・親子・範囲制限を初期状態に戻した場合に利用できます。レイヤー上限は全体で32、親子／シーンの深さは既存の制限に従います。旧プロジェクトは従来どおり読み込めます。

## MCPの一括編集

`project.transaction` は1〜100件の編集を候補プロジェクトで検証し、すべて成功した場合に1回のUndoとして反映します。失敗時は編集状態を変えません。`dryRun:true` は候補を返すだけで、音声生成も開始しません。`vmm_state` の `revision` を `expectedRevision` に指定すると、状態取得後に他の編集が行われた場合はエラーとして拒否します。revisionは起動中のみ有効で、再起動後は取り直してください。

対応コマンドは `clip.add` / `clip.update` / `clip.delete` / `track.add` / `track.update` / `track.move` / `project.update`。ファイル読み込み・保存・外部処理は個別のジョブで実行します。作成アイテムの `ref` は後続操作のID欄で `$ref` として参照できます。本文の `$` は通常の文字として保持します。

MCPの `tools/call` のパラメータ例です。

```json
{
  "name": "vmm_project_transaction",
  "arguments": {
  "expectedRevision": 12,
  "dryRun": true,
  "operations": [
    {"command":"clip.add","kind":"group","track":0,"ref":"scene","properties":{"start":0,"duration":4}},
    {"command":"clip.add","kind":"text","track":1,"ref":"caption","properties":{"parentID":"$scene","text":"こんにちは","start":0,"duration":4}},
    {"command":"clip.update","clipID":"$caption","properties":{"color":"33CC77"}}
  ]
  }
}
```

候補を確認し、最新revisionを取得して `dryRun:false` で反映します。MCP接続は通常起動時に無効で、同一ユーザーの認証付きローカル接続を使用します。

## 複数キャラの字幕編集

制作機能→キャラ設定→「プロジェクトのキャラ」で登場人物を追加する。リストには字幕色と割り当て済み字幕の件数を表示する。「字幕」で6色のテンプレート（標準・白、緑、水色、ピンク、黄色、オレンジ）を選ぶと、色・フォント・縁・影・サイズ・位置・中央揃え・最大幅をキャラ定義に保存する。色などはその後自由に編集できる。プレビューは実際のFrameRendererを利用する。

既存字幕への反映は明示操作。「このキャラの字幕だけに反映」は、そのキャラIDの字幕のみ更新し、音声設定・生成状態・立ち絵・キーフレームを保持する。「このキャラの字幕を選択」でタイムライン上の対象をまとめて選択できる。「選択字幕の装飾を取り込む」は色・装飾・サイズに加えて位置も取り込む。対象にロックがある場合、一括反映は途中まで変更せず中止する。変更はUndo可能。

脚本画面にキャラ別フィルターと未割り当てフィルターを追加。各行のキャラメニューは割り当て済みの名前と字幕色を表示する。TXTの「キャラ名：セリフ」は既存のキャラ名による自動割り当てを利用できる。プロジェクトごとの設定は.vmmへ保存され、従来の共有プリセットも利用できる。

同じ音声エンジン・話者を使う複数キャラの立ち絵は、キャラIDが割り当てられていればそのキャラのセリフだけに口パクする。キャラIDのない旧立ち絵は従来の話者による判定を維持する。
