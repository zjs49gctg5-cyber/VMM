# JSONアニメーション定義・プリセット

VMM専用の宣言型JSON拡張とJavaScriptCoreを使う定義に対応しています。[JavaScriptの仕様](JAVASCRIPT-ANIMATIONS.md)を参照してください。Developer ID署名や公証、外部パッケージは不要です。version 1は宣言型JSON専用です。WindowsのDLL、Lua、任意のネイティブ実行コードは読み込みません。

## 操作

1. 設定 → 拡張 →「拡張JSONを読み込む…」で `.vmmext.json` を導入します。確認画面に作者、版、内容の件数を表示します。同じIDの更新は確認後に置き換えます。
2. 「サンプル拡張を追加」でも基本モーションを導入できます。上下の波・周回運動と、フェード・ポン出し・スライドのプリセットを収録しています。
3. アイテムを選択し、アニメーション編集 → カスタムで定義を選び、振幅・回数等を設定して「キーフレームを生成・適用」を押します。振幅は画面の幅／高さに対する割合で、UIでは％表示します。縦横比によって周回の軌道は楕円になります。
4. 通常のキー編集と再生で調整できます。定義が対象とする項目のキーフレームだけを置換し、他の項目と登場・退場・反復設定は保持します。適用は1回のUndoで戻せます。
5. 同梱プリセットはアニメーション編集の「VMMプリセット」→ 拡張名から適用します。既存プリセットと同様、プリセットに含まれる設定の種類を置換します。

設定の拡張一覧で有効／無効、削除、JSON書き出しができます。無効化した拡張は新規の定義／プリセット候補から隠れます。導入・無効化・削除はプロジェクトを変更しません。適用済みのキー、定義のコピー、パラメータは `.vmm` 内に残るため、未導入のMacでも同じキーで再生・書き出しでき、カスタム画面の「プロジェクト内の定義」で再生成できます。手で編集したキーは再生成すると対象項目だけ置き換わります。読み込み・再生・書き出し時に自動再生成は行いません。

アイテムごとに最後に適用した定義1件を再編集用に保存します。複数の定義を順に適用して残った別項目のキーも再生できますが、以前のパラメータ履歴は保持しません。

## JSON形式

実際に読み込めるサンプルは [basic-motion.vmmext.json](../examples/extensions/basic-motion.vmmext.json) を参照してください。拡張は単一JSONファイルで、素材・ZIP・ネイティブ実行ファイルを含みません。version 2のJavaScript定義は生成時だけ別プロセスで実行します。

```json
{
  "version": 1,
  "id": "example.fade",
  "name": "透明度アニメーション",
  "author": "Example",
  "revision": "1.0",
  "animations": [{
    "id": "fade",
    "name": "指定した透明度まで表示",
    "parameters": [{
      "id": "target", "title": "終了時の不透明度",
      "minimum": 0, "maximum": 1, "defaultValue": 1, "unit": "%"
    }],
    "tracks": [{
      "property": "opacity", "offset": false,
      "expression": {
        "op": "multiply",
        "args": [{"op": "time"}, {"op": "parameter", "parameter": "target"}]
      }
    }]
  }],
  "presets": []
}
```

必須フィールドは上記にある項目です。`description`、パラメータの `unit` は任意です。`id` は英数字・ドット・ハイフン・アンダースコアの1〜100文字で、拡張と定義の安定した識別子です。`revision` は表示用の文字列です。同じ拡張IDを更新しても、既存プロジェクトのコピーは自動更新しません。

`property` は既存AnimatedPropertyのJSON名（`x`, `y`, `scale`, `opacity`, `rotation`, `volume`, `regionWidth`, `regionHeight` 等）を使います。アイテムが対応するプロパティだけ適用できます。同一の定義に同じプロパティを重複させることはできません。

式の値とパラメータは内部単位です。`x`／`y` は画面に対する割合、`scale`／`opacity`／`volume` は倍率・割合、`rotation` は度です。`unit: "%"` はUI表示を100倍する指定で、JSONの1は100％です。`offset: true` は式の結果をアイテムの基準値に加算し、`false` は式の結果を直接設定します。最終値をプロパティの有効範囲に制限します。

| op | 引数数 | 意味 |
| --- | ---: | --- |
| constant | 0 | `value` の数値 |
| parameter | 0 | `parameter` のIDの値 |
| time | 0 | アイテム区間の進行0〜1 |
| seconds | 0 | 区間の開始からの秒数 |
| base | 0 | 対象プロパティの基準値 |
| add / subtract / multiply / divide | 2 | 加減乗除 |
| sin / cos | 1 | ラジアンで三角関数 |
| min / max | 2 | 最小／最大 |
| clamp | 3 | 値・下限・上限 |
| lerp | 3 | 開始値・終了値・進行率 |
| curve | 1 | `curve` に保存した既存EasingCurveで進行率を変換 |

`curve` の内容は既存 `.vmmfx.json` に保存したキーの `customCurve` と同じ形式です。パラメータは有限の数値で、単位は省略／`%`／`°`／`秒`／`回` に対応します。プリセット配列の各要素は既存EffectPresetのJSON（`version: 1` と `name` が必須）です。既存 `.vmmfx.json` の内容をそのまま配列に入れられます。素材参照を含むプリセットには別途プロジェクト内で必要な素材が必要です。

## 変換精度と上限

式をプロジェクトFPSのフレーム時刻と区間終端で評価し、線形補間のキーに変換します。保存済みの開始時刻オフセットを含めるので、トリムされたアイテムにも適用できます。生成後の分割・トリムは従来のキーフレームと同じ挙動です。

割合プロパティはサンプル時刻の値の誤差0.0001以内（0.01パーセントポイント）、その他は0.05以内に保ってキーを間引きます。これはフレーム時刻での精度で、式の連続時間全体の誤差保証ではありません。プロジェクトFPSで捉えられない高周波の振動は作らないでください。異なる出力FPSでも保存済みキーを線形補間して再現し、式を再評価しません。

- JSONは1MiBまで。導入32パッケージ、一覧合計16MiBまで。
- 1パッケージはアニメーション16件、プリセット32件まで。
- 1定義はパラメータ12件・対象項目12件、式の深さ12・合計256ノードまで。
- 生成は20,000フレームまで、フレーム数×式ノード数は200万まで。各項目は500キーまで。
- 不正な構造、未知の命令・参照、範囲外パラメータ、ゼロ除算、非有限値、上限超過はエラーにし、適用前のプロジェクトを維持します。精度維持ができないときは振動数を下げるか区間を分割します。

## 外部操作（MCP）

MCP接続は通常起動時に無効で、同一ユーザーの認証付きローカル接続を使用します。以下はMCPツール名です。

- `vmm_extensions`：導入済みパッケージと無効ID一覧。
- `vmm_extension_install`：`package` にパッケージJSON。更新時は明示的な `replace: true` が必要。
- `vmm_extension_enable`：`packageID`、`enabled`。
- `vmm_extension_remove`：`packageID`。
- `vmm_animation_applyDefinition`：`clipID`、`packageID`、`definitionID`、任意の `values`（パラメータID→数値）。有効な導入済み定義だけ適用。
- `vmm_extension_applyPreset`：`clipID`、`packageID`、`name`。
