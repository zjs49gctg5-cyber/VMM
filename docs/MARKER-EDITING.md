# マーカー編集

タイムラインの時間目盛りの下に、マーカー専用の行があります。近いマーカーではラベルの幅を調整して重なりを抑えます。同じ時刻のマーカーは一覧から個別に選べます。

- 追加：ツールバーの旗＋、マーカー行の空白をダブルクリック、右クリックの追加、ショートカット（標準M）。
- 移動：マーカーをドラッグ。プロジェクトFPSのフレーム単位で確定し、1回のUndoで戻せます。Escapeはドラッグ取消。
- 編集：マーカーをダブルクリック、または右クリックの「マーカーを編集」。
- 一覧：「マーカー一覧」で選択し、名前・秒数を入力して適用。「再生位置の時刻を使う」で現在の時刻を入力できます。
- ジャンプ：マーカーをクリック、一覧の移動、ツールバーの前／次ボタン。
- 削除：右クリック・一覧の削除、またはタイムライン上でマーカーを選んでDelete。クリップは削除しません。

マーカーとイン／アウト範囲は別々に操作します。範囲の設定・ループは「範囲」メニューにあります。

動画末尾より後のマーカーも編集・ジャンプできます。マーカーによって動画の書き出し時間は延長しません。保存形式は従来どおりで、名前は200文字・時刻は0〜86400秒・最大2000個の制限を保ちます。
