# マーカー・範囲・字幕

マーカーの追加・編集方法は[マーカー編集](MARKER-EDITING.md)を参照してください。イン／アウトはタイムラインの「範囲」メニューまたはI/Oキーで設定し、範囲ループにも使えます。書き出し画面では「イン／アウト範囲」で範囲を明示的に反映します。マーカーと範囲はプロジェクトに保存され、Undoに対応します。

台本ワークスペースの「字幕ファイル」からUTF-8 SRT/VTTを読み込み・出力できます。読み込みは選択レイヤーの現在位置を起点に字幕テキストを配置し、音声は自動生成しません。読み込んだ字幕は選択された状態になるため、同じメニューの「選択テキストをセリフに変換」でまとめてセリフにできます。変換時は位置・装飾・時間を保ち、現在の音声エンジンと接続中の先頭の話者を設定します。必要に応じて話者を変更し、「音声を生成」から生成してください。変換したセリフは生成時も元の長さを維持します。音声が長すぎる場合は末尾で切れるので、話速や長さを調整してください。長さを音声に合わせたい場合は、アイテム設定の「音声生成時に長さを維持」をオフにして再生成します。時刻をプロジェクトのフレーム単位へ丸め、最大2,000字幕・8MiB・24時間です。空字幕・15字/秒超・4行以上・同一レイヤーの重なりを診断し、クリックで該当アイテムへ移動できます。

VTTは本文と時刻を読み込みます。NOTE/STYLE/REGIONブロック、cueの位置・縦書き・CSS・ルビ等は再現しません。マークアップは除去し、基本的な文字参照を復元します。出力は可視レイヤーの字幕を対象に、親の表示時間で切り詰めます。音声読み上げ用テキストではなく字幕本文を出力します。

## 音声から字幕を作成

音声・動画・生成済みセリフを1つ選び、台本ワークスペースの「字幕ファイル」→「音声から字幕を作成」を開きます。言語と字幕を置くレイヤーを選び、「文字起こしを開始」を押します。初回はmacOSの音声認識の許可が必要です。端末内認識が使える場合だけ処理し、クラウド認識へ自動で切り替えることはありません。字幕の文章と時刻を確認・修正してから「字幕を作成」を押します。ひとまとめにUndoできます。

対象は使用区間の長さと、その区間に対応する元素材の長さがそれぞれ55秒以内のアイテムです。長い音声は先に分割して処理してください。トリムと速度変更は字幕の時刻に反映します。音量、EQ、音程などの加工は認識対象に含めません。認識結果は誤りや時刻のずれがあり得ます。認識中にプロジェクトや選択が変更された場合、古い結果は適用できないため、選び直して再実行してください。

## 長いセリフの字幕を分割する

1. 制作機能の台本でセリフの「字幕を分割」を押します。音声生成中やロック中のレイヤーでは操作できません。
2. 提案された文章と開始・終了フレームを確認して修正します。各行の再生ボタンでその時刻から音声を聞け、ハサミで字幕をさらに分割できます。時刻は文字数で配分した目安であり、音声認識による自動同期ではありません。
3. 「字幕を作成」を押すと、元のセリフ音声を維持したまま、分割された字幕がテキストアイテムとして配置されます。一度のUndoで取り消せます。

元のセリフの字幕は非表示になります。元のセリフを選ぶと、アイテム設定の「セリフの字幕を表示」で再表示できます（作成済みのテキスト字幕は別途削除してください）。生成時に元セリフの長さが変わらない設定になります。分割後に音声の文章や長さを変更した場合、独立したテキスト字幕は自動では追従しないので、タイミングや内容を調整してください。親グループがある場合は同じ親に配置され、字幕の出力範囲も親の表示時間に制限されます。
